# Checking an AI-disclosure label

Some email from Complexio's Enterprise Automator is written by an AI system. That email says so
in a short note at the bottom ("This email was generated by an AI system …"), and it also
carries a machine-readable label. This page explains what the label means and how to check it.

## What the label means

The label says that an AI system wrote the message, and on whose behalf it was sent. It does not
say that the content is correct: treat the message as you would any other, and check anything
important before acting on it. A person may have reviewed or amended the text before the system
sent it; the label is the same either way.

You need no tool to read the disclosure: the note at the bottom of the message is the
disclosure. The check below is for anyone who wants to confirm that the label is genuine and
that the labelled text has not been changed.

## How to check a message

Save the message as an `.eml` file (most mail clients offer "Save as" or "Download message").
Then, with Python 3.12 or later:

```
git clone https://github.com/quintessential-ai/ai-disclosure
pip install ./ai-disclosure/detector
ai-disclosure-verify message.eml
```

The command prints one of the results below and what it means. It also reads an HTML body, an
Office file (`.docx`, `.xlsx`, `.pptx`) or a PDF written by Complexio Stevie.

It fetches the public key set over HTTPS by default, only when the message carries a signed
label (`--timeout SECONDS` sets how long it waits; the default is 10). To check against a local
copy of the key set, or without the network:

```
ai-disclosure-verify message.eml --jwks jwks.json
ai-disclosure-verify message.eml --offline      # signed labels read as `ai_marked_unverified`
```

`--json` prints the report as JSON. The exit status is 0 for `verified`, 1 for `no_marker`,
2 when the message or key set cannot be read (or for `unparseable`), 3 for
`ai_marked_unverified` and `quoted_only`, and 4 for `verified_with_unmarked_content`.

## What each result means

| Result | What it means |
| --- | --- |
| `verified` | The label is genuine: Complexio's system wrote the message and signed it. Its words and links are the ones signed, and the message contains nothing else. The check ignores spacing (`1 000` and `1000` read the same) and how the text is laid out, and it checks where each link goes, not how much of the text the link covers. |
| `verified_with_unmarked_content` | The label is genuine and the signed words and links have not changed. But the message also carries something the label does not cover, so do not treat that part as covered: for example, a quoted earlier email, formatting that could change how the text is shown, or another part of the email, such as a plain-text version that differs. A PDF never reads better than this (see below). |
| `ai_marked_unverified` | The message says it was written by an AI system, but the check could not confirm the label. For example, the text was changed after it was signed, or the label is not signed. |
| `quoted_only` | This message is not labelled itself. It only quotes an earlier labelled message. |
| `no_marker` | The message carries no AI-disclosure label. |
| `unparseable` | The message could not be read safely (it is too large, nested too deeply, or malformed), so nothing in it was checked. |

A result other than `verified` never means a person wrote the message. It only means the check
cannot confirm the label.

A PDF's label is written as an update appended to the finished file, and the label cannot sign
the update that carries it. Anything else in that update, page changes included, is not
covered, so a genuine PDF label reads `verified_with_unmarked_content`, never `verified`.

Until a deployment's signing key is published in the key set, its labels are unsigned, and
every check of its mail reads `ai_marked_unverified`.
